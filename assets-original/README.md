# Original assets

Photographs and files from the earlier version of the site, kept because they
are the only copies.

They used to sit in `public_html/`. That folder is now the built website —
Hostinger's Git deployment publishes it verbatim — so anything left there would
be served at the root of niteshacars.in, and anything the build did not produce
would be wiped by the next build. Nothing references these, so they moved here
rather than being deleted.

`backgound Bmw.png` is the source of `my-app/public/open-road.webp`.
`brezza1.avif` is a Brezza; `my-app/public/photos/car-brezza.avif` is the copy
the fleet cards actually use.
