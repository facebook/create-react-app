# Nova Drive — Self-Driving Car Website

A static, single-page marketing site for a fictional autonomous vehicle company. Plain HTML/CSS/JS, no build step required.

## Sections

- Hero with animated stats
- Feature highlights
- "How it works" ride flow
- Technology specs with a sensor diagram
- Safety stats
- Testimonials
- Demo request form
- Footer

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
cd self-drive-car-website
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
